# Code audit 2026-10-18

The state of the code after the audit of 2026-10-15 and its four phases
(0.94.0–0.97.0): what drifted again, where a question is still answered
twice, how readable the long modules are, whether names say one thing, and
which small helpers are copied where one home would do. Every line cited
was read at that line; the three bugs were reproduced. State at the audit:
`main` at `1c426bc` (0.97.0 plus Unreleased), suite 1148 passed, ruff and
pyright clean. The German record of this review is the project note
`notes/audit-2026-10-18-codequalitaet.md`.

## Summary

The copies the audit of 2026-10-15 removed stayed removed: git runs only
through `repo`, digests only through `scope_sha`, the answering run is
chosen only by `runs.bound_answering_run`, the repo-wide protocol scan is
`repo.repo_protocols`, the id alphabet is asked of `promises`.
`tests/test_one_home.py` holds exactly those shapes. What remains sits one
level below its grep: shapes it does not see (a fence toggled by hand,
path rendering, timestamps, refusals on stdout), three moves finished only
halfway (refusals to stderr, `gate.Findings` in code-check, audit bug 11)
and a handful of long functions that mix a station list with its logic.

## What holds

`repo` holds git, the protocol glob, the pin grammars and the area name;
`runs` is the one reader (completion, answering choice, repeats,
`write_atomic` for every record file and the lease); `scope_sha` is the only
hashlib; `console.refuse`/`exit_with` are small and called by every `cli()`;
`runs.bound_answering_run` + `AnsweringRun.explain` is genuinely the one
choice (finalize `:171-194`, intent_check `:321-347`, recheck `:74-78`);
`preflight.area_tests` is one home for both gates; `protocol_fill`,
`protocol_reading` and `scaffold.auto_fill_deterministic` go through
`protocol_check.fields`/`model_named`; `findings` is a clean single-shape
reader; the hooks judge at one point (`command_segments`); `cold_reader` is a
clean 97-line home. Ruff reports no unused import or argument.
