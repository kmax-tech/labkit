## Overall

The structure holds and is enforced by tests: no import from a lower layer to a higher one, one collector (`gate.Findings`) for six gates, and each of the three entry points lists its stations in order in one function. The simple model — a check is a pure function, the gate calls it — describes a core, not the package: 11 of the 58 functions named `check_*` have the reference form, and 26 functions run under the `pure_call` guard. The dominant problem class is not a condition decided twice but **several shapes for one thing**: what a check returns, through which channel a finding is told, and where its sentence, grade and rule are written.

## Findings

### Shapes of a check

- **V** `docs/architecture.md:36` — the name `check_` covers five kinds of function. Of 58: 11 reference form (pure, return `list[GateFinding]`), 6 return findings but read files or git, 24 stations that take a `Findings` collector, 12 with another result (bool, str, report object), 5 where "check" is a noun. Of the 26 functions under `pure_call`, 15 are not named `check_*`. A search for `def check_` finds neither the pure checks nor only them; the inventory tool is the one reliable index.
- **V** Three stations return data beside reporting, and the caller's flow reads it: `check_answering_run` returns the run (`labkit/gates/finalize.py:291`), `check_data_counts` a bool for the closing line (`labkit/gates/finalize.py:573`), `check_audit_records` the records (`labkit/gates/preflight.py:467`).
- **R** A finding is told through four channels: a gate finding, `raise SystemExit` (`labkit/run/start_check.py`, 23 sites, by design of `formats/console.py:49`), a printed `WARNING` line, and a sentence the caller grades (`labkit/formats/audit_gaps.py:101`, `labkit/formats/protocol_history.py:236` with the grade inside the string).
- **V** Three blockers of report-check bypass the collector and set the exit by hand, so no summary counts them: `labkit/gates/report_check.py:596`, `:1250`, `:1310`.

## Open points

1. Reserve `check_` for the pure form and rename the 24 stations (for example `station_*`): a mechanical rename, after which the name finds the pure checks.
2. Replace the text comparison at `labkit/gates/report_check.py:656` by a datum on the finding: rewording a sentence can then no longer tell a cause twice.
3. Give the unreadable `[result]` table one home (`declared_run_gaps`), report-check takes finalize's finding: one blocker instead of two for one cause.
4. One documentation commit: the skip token, seven modules, the "Holds" column, and the sentence that a station may return data.
5. Derive the rule citation in a sentence from the recorded datum: text and datum cannot diverge; about 51 sentences change.
6. Record the remaining shapes as limits in `docs/architecture.md` instead of converting them (the run start's exits, the per-gate sentences, the sentence-returning gaps): the model then states three named shapes, and no further restructuring follows.
