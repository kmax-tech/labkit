# Repo audit 2026-10-23

Four questions: are the checks clear, is every verdict recorded in one
place, is the design stable, is there drift. State at the audit: `main` at
`b4cd032` (v0.103.0 plus 62 commits, Unreleased), tree clean,
`.githooks/pre-commit` (ruff, format, pyright, pytest) green, 27 s. Three
readers (clarity, drift, homes) ran in parallel; every finding below was
opened at its line before it was listed. Line numbers are those of
`b4cd032`.

## Summary

The architecture holds: layers, the module table, git, digests, run
records and rule ids each have one home, and tests hold them
(`tests/test_architecture.py`, `tests/test_one_home.py`,
`tests/test_rules.py`). The dominant problem class is drift from the
pace of format changes: the shipped standard, the stamped AGENTS.md and
the Unreleased CHANGELOG lag the code by one or two renames. Gate
verdicts are not recorded at all — only model audits are; that is a
design choice nowhere written down.

## Where verdicts are recorded

| Record | Writer |
|---|---|
| `audits/<min>-<mode>.toml`, decisions in place | `findings.write`, `findings.write_decision` |
| `audits/<min>-<mode>-failed.toml` | `findings.write_failed` |
| `audits/<min>-review(-N).toml` | `reviews.write_review` |
| `runs/<id>/*.json`, `runs.tsv` | `runlog`, `runs.write_failure` |
| `.git/labkit-sessions.jsonl` (session → runs, no verdict) | `claude_hooks.record_session` |

preflight, finalize, report-check, protocol-check, intent-check,
code-check, notes-check leave stdout and an exit code only — by design
they are recomputed, not logged, but no docstring says so. Audit records
carry `run_id` (analysis) but no protocol id or path: in an area with
several protocols the match is computed against the current text, not
looked up. "What did all gates say about run X" has no single place.

## Stability

Layers and module table: stable, test-held. File formats and the
standard: not. Since 2026-10-12 eleven releases carried a Breaking
section (0.87, 0.89, 0.90, 0.93, 0.94, 0.98–0.103), Unreleased has
Breaking entries again, and the standard went 0.20 → 0.21 (2026-10-22)
→ 0.22 (2026-10-23, unreleased). 587 commits in the last two weeks. Each
change itself carries a migration sentence; the drift findings D1–D5 are
the cost of that pace — prose shipped to other labs trails the code.
