per question" table (`docs/architecture.md`), and duplicated logic. Every
finding below was reproduced with a script or read in the code at the line
named; nothing is a guess. The work order it produced is `TODO.md`, section

## Drift and duplicated logic

- **"Which run answers" has three answers**: `runs.bound_answering_run` (the
  home), `recheck.run_dir`, `usability.latest_run` (`labkit/usability.py:731`,
  the same code as recheck's default branch). On top, four hand-written
  renderings of `AnsweringRun` with different semantics: finalize blocks on
  missing intent keys, intent-check warns, params ignores it, audit ignores
  exclusions.
- **Fences are parsed four times with three regexes**: `protocol_fill._FENCE`
  closes on `startswith` (a ```` ```text ```` line closes a block),
  `code_check.FENCE` knows no tildes and no nesting; only
  `protocol_block.fenced_blocks` is right. The prompt-drift check and
  `--prompts` disagree with the protocol parser.
- **A second label parser** in `code_check.PROMPT_FIELD`
  (`labkit/code_check.py:1063`) — the bug class `protocol_fill` removed on
  2026-10-07.
- **"Does the protocol name a model?"** answered twice: `protocol_check._NO_MODEL`
  on the parsed field, `scaffold.NO_MODEL` on raw text with one exact spelling.
  `**Model / tool:** —` is model-free for protocol-check and not for `--report`.
- **The id alphabet outside `promises`**: `labkit/usability.py:1119` (`^a\d+_`),
  `labkit/protocol_reading.py:161` (`[ca]`).
- **The repo-wide `PROTOCOL-*.md` scan has no home**: four `rglob`s, only
  `repo_check` skips `.venv`, `runs/`, `data/`; a protocol copied under
  `runs/<id>/` is a false "two protocols carry id" blocker. The name shape is
  spelled five ways.
- **The repo root is found by five rules again** (repo.py records three as
  fixed on 2026-10-06): `notes_check.repo_root` copies `git_root`;
  `scaffold.lab_root` and `llm._find_models_toml` answer "where is the lab"
  differently.
- **Digests by hand**: `runlog._script_sha` (`labkit/run/runlog.py:669`) spells
  sha256 although `file_digest` is imported; width 12 as a literal. Widths
  overall: stamp 12, data files 16, outputs 16, lock 12, each a literal.
- **git outside `repo.git_run`**: `runlog._checkout_head`
  (`labkit/run/runlog.py:283`), no timeout, no `GitError`; `usability._sh` eight
  times.
- **The requirements grammar three times**: `repo`, `runlog._parse_lock`,
  `usability.py:640` (`startswith("labkit")`).
- **Gate findings in five shapes**: a `Findings` dataclass (finalize), two
  counters plus inline prints (preflight), `BLOCKER · ` strings counted by
  `startswith` (code_check — and preflight counts the same strings again),
  lists (report_check), tuples (notes_check); three spellings of the grade.
- **"Repo-relative, else absolute"** about twelve times, six in `audit.py`
  alone; `runlog.py:807` relativises an unresolved path.
- **The area name `NN-name`** by four regexes; `code_check.AREA_IN_PATH`
  accepts two digits and lower case only.
- **`protocol_fill.HEAD_TYPE`** searches `type = "<…>"` in the whole text, not
  in the TOML block — the case `protocol_block` guards against.
- Docs: README says "seven stations" and lists eight, "eight steps" and lists
  seven; `docs/standard-cut.tsv` and `standard-terms.tsv` are cited only by
  TODO and CHANGELOG; refusals go 44 times to stdout and 25 times to stderr;
  CLAUDE.md's "passes in a fresh clone" holds only for a clone with tags.
