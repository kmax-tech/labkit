# Repo audit: clarity, doubled homes, drift between prose and code

2026-11-26, at commit `6e58d579` (0.116.0 plus 18 unreleased commits). The author asked whether labkit is clear and logical and whether each piece of logic has one home. This note is the register of what was found; nothing was fixed. The open decisions stand in `TODO.md`.

## How it was read

Ground truth first: `.githooks/checks full` ended with exit 0 on this state, and all 140 modules import from a `git archive` of HEAD. The package holds about 78 000 lines (`labkit/formats` 25 800, `labkit/gates` 18 800, `labkit/checks` 11 000), the tests 96 000.

Three readers that did not write the code read in parallel, each read-only and without running tests. The session that ordered them opened the lines of the findings marked "confirmed" below; the others rest on the reader alone.

## Overall

The large questions have one home each (git, sha256, the protocol scan, the run directory, the status words, the kinds and cost tiers), and tests hold them: `tests/test_one_home.py`, `tests/test_architecture.py`, `tests/test_readme_commands.py`, `tests/test_public_api.py`, `tests/test_rules.py`. The drift reader found no prose that names something that does not exist: 716 `module.name` references, 22 console commands and 569 rule citations resolve. The three entry points list their stages flat and keep the conditions literally in the body.

The dominant problem class is not a bug but vocabulary and repeated wording: one word for several things, docstrings that disagree with the body, and sentences or small formulas written by hand where a constant or builder exists.

## Where a newcomer misreads

- **`held` names at least six things** in `gates/finalize.py` and `gates/report_check.py`: the area's audit evidence, origin runs whose check passed, a result object, the run choice, a tuple of blocker texts, a set of report paths. At `labkit/gates/report_check.py:1187` a status string is bound to `state`, which held the area's state before.
- **Three numberings with the same numbers.** `preflight` has stations 0–9, `finalize` 0–10, the report-check chain its own 0–8 and cites "station 2" and "station 4" (`labkit/gates/report_check.py:974`–`1021`); chain station 4 is not finalize's station 4.
- **A negated flag**: `same_text = ctx.file_state != PROPOSED`, read as `not same_text` at two conditions (`labkit/gates/report_check.py:1033`).
- **`hold_report` and `hold_reported`** differ by one letter and by what they hold: one report file (`labkit/gates/report_hold.py:949`), the changed paths (`labkit/gates/report_check.py:1365`).
- **"finding" and "open" each mean several things**: `formats/findings.py` holds audit records, `gate.Findings` collects a gate's lines; "open" is an undecided audit finding, an unfilled field, and a rule not yet decided.
- **A blocker that depends on order**: the same unreadable scope file blocks or is only noted, depending on whether an earlier station blocked (`labkit/gates/preflight.py:643`). Documented at `labkit/gates/preflight.py:320`, but the station's outcome is not a function of its inputs.
- **Conditions behind a field name**: `if not lane(head.repeat_cost).provenance:` (`labkit/gates/finalize.py:1327`) where the flow docstring says "only for repeat_cost = low".
- **Large modules without named parts**: `formats/findings.py` (2 530 lines: data model, request grammar, decision rules, TOML writer and parser, record status, ways out); `formats/scope_sha.py` (stamp, import closure, test discovery, evidence bases, pin, a command line). `finalize` and `report_check` import shared test logic from `gates/preflight.py`.

## Prose that is incomplete

All reader only except the first; none sends a user into an error.

- `[[evidence_file]]` is missing where `docs/promise-block.md:57` and `docs/architecture.md:155` list what the protocol's block holds (confirmed: neither file names it). The table came with the merge of 2026-11-26.
- `labkit-init exp --deliverable` and `--deliverable-columns` are missing in `labkit/tools/scaffold.py:4` and `README.md:145`.
- `protocol-fill --freeze` is missing in the module docstring (`labkit/tools/protocol_fill.py:12`), the only writer of the freeze.
- `runlog --max-seconds` (default 90, then exit 3), `--interval` and `--notify` are missing in `README.md:180`.
- `--protocol FILE` is named for three commands in the README and missing for `preflight`, `finalize`, `labkit-audit` and `labkit-params`.
- `README.md:286` places historical audits under `docs/`; they lie under `docs/notes/`.

## Solved well

- `protocol_block.PROTOCOL_KINDS` and `runs.REPEAT_COSTS`: the names are unpacked from the list (`labkit/formats/standard_contract.py:47`), so a second spelling cannot arise, and argparse reads the same list.
- `repo.SKIP_DIRS`: three modules build their pattern from the set (`labkit/formats/repo.py:309`).
- `findings.open_findings` (`labkit/formats/findings.py:1205`): one table in the docstring gives every gate's rule for an undecided finding.
- `standard_contract.Lane`: one decision table, `lane()` its one answer.
- `finalize_area` and `preflight_area` state that every condition is in the function, and the skips are literal at the call sites.
