## Exact r2: cost (2026-11-16)

Review D timed single calls of the exact r2: 0.69 s at 5 000 items, which it extrapolated to about 139 s per evaluation with 200 permutations. Measured again on the same machine (Python 3.12.7), single calls of `_r2` only, on review D's two data kinds and a Gaussian one, ten calls each with the gold permuted: 24–35 ms per call at 5 000 items. A whole evaluation through the skeleton was not timed, by review D either: its 139 s are one call times 201. Review D's own script, rerun with its inputs (seed 1) five times: 34 ms per call at 5 000 items each time. So neither the code nor the inputs explain the factor of 20; the conditions of the earlier run cannot be reconstructed, and why it differs is not known. An integer form of the same rational — every float is m/2^k, so all values scale to integers over the largest denominator — gave the identical value on every case tried (constant predictions, missing ones, exponents from 1e-300 to 1e300) at 4.6–5.3 ms per call. Decided by the author 2026-11-16: r2 stays as it is for now. Script and log internal (labkit-evidence `usability/2026-11-15-usage-round-24-acceptance/r2-timing/`).
