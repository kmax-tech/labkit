## Implementation Error Found and Fixed

The initial measurement (run 2026-10-28T16-45-10_2e29) revealed a critical implementation error: the `ScreeningModel.probability()` method was dividing by `sd**2` (variance) instead of `sd` (standard deviation) during feature standardization. This violated the registered specification which requires standardization by subtracting the mean and dividing by the standard deviation.

The error was corrected in `experiments/01-apply-screen/scripts/01_measure.py` line 196, changing:
```python
w * (v - mu) / sd**2  # WRONG
```
to:
```python
w * (v - mu) / sd     # CORRECT
```
