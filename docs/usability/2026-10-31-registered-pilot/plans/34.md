# Plan: hrv-indices

The plan for this task, written before any work on it. Follow it; where it cannot be followed, say so in REPORT.md.

- **Terms:** R-peaks: the peaks neurokit2 0.2.12's `ecg_peaks(ecg, sampling_rate=100)` finds in the ECG column with its default method ("neurokit") and without artifact correction (`correct_artifacts=False`, the default); HRV indices: what neurokit2 0.2.12's `hrv(peaks, sampling_rate=100)` returns for those peaks, under the column names the task section below lists; deliverable: pred_results/hrv_analysis_pred.csv, one header row and one data row, exactly the task's columns in the task's order
- **Question / hypothesis:** What are the time-, frequency- and non-linear-domain HRV indices of the resting ECG in bio_resting_5min_100hz.csv, computed from its R-peaks?
- **Data / scope:** benchmark/datasets/biosignals/bio_resting_5min_100hz.csv as supplied with the task, its ECG column, five minutes at 100 Hz; the files are used as supplied, not copied or changed
- **Exclusions / filters:** none — no beat is removed or corrected. A column stays empty only when `hrv()` returns no value for its index because the index is not defined for this recording (for example a window longer than the five minutes); the report names each empty column with that reason. A missing package, an exception or an aborted call is a failed run, never an empty column
- **Unit:** the one recording; the kept number is HRV_MeanNN in milliseconds, and the deliverable carries every index the task lists
