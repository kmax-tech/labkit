# Plan: hrv-indices

The plan for this task, written before any work on it. Follow it; where it cannot be followed, say so in REPORT.md.

- **Terms:** R-peaks: the peaks NeuroKit2's ECG peak detection finds in the ECG column at the recording's 100 Hz; HRV indices: the time-, frequency- and non-linear-domain indices NeuroKit2's hrv() computes from those peaks, under the column names the task lists; deliverable: pred_results/hrv_analysis_pred.csv, one header row and one data row, exactly the task's columns in the task's order
- **Question / hypothesis:** What are the time-, frequency- and non-linear-domain HRV indices of the resting ECG in bio_resting_5min_100hz.csv, computed from its R-peaks?
- **Data / scope:** benchmark/datasets/biosignals/bio_resting_5min_100hz.csv as supplied with the task, its ECG column, five minutes at 100 Hz; the file is used as supplied, not copied or changed
- **Exclusions / filters:** none — no beat is removed or corrected beyond what NeuroKit2 does; an index that cannot be computed from this recording stays empty in its column, never filled, guessed or dropped
- **Unit:** the one recording; the kept number is HRV_MeanNN in milliseconds, and the deliverable carries every index the task lists
