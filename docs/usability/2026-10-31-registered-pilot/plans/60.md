# Plan: nvc-improvement

The plan for this task, written before any work on it. Follow it; where it cannot be followed, say so in REPORT.md.

- **Terms:** syllogism: one of the 64 tasks in CCOBRA's encoding (AA1 … OO4); MFA (most frequent answer): for each syllogism, the response that most participants of Ragni2016 gave, counted over the nine responses in CCOBRA's response order — on a tie the first in that order (researcher's precision: the task names no tie rule); hit: 1 divided by the number of predicted responses when the MFA is among them, else 0; rule-applied prediction (researcher's precision of the task's "improvements achieved by the NVC rules"): NVC alone when the rule predicts NVC for the syllogism, else the model's prediction unchanged; improvement: hit of the rule-applied prediction minus hit of the model's prediction; deliverable: pred_results/accuracies.csv with the task's columns in the task's order, 2,240 rows
- **Question / hypothesis:** For each of the seven models, five NVC rules and 64 syllogisms, how does applying the rule change the model's hit against the MFA of Ragni2016, and what is the mean improvement over all 2,240 combinations?
- **Data / scope:** benchmark/datasets/nvc/Ragni2016.csv (the participants' responses), the seven prediction files in benchmark/datasets/nvc/scripts/prediction_errors/models/ and the five rule implementations in benchmark/datasets/nvc/scripts/prediction_errors/rules/, as supplied; never accuracies_data_for_plot.csv or ind_data_for_plot.csv; the files are used as supplied, not copied or changed
- **Exclusions / filters:** none — every model, rule and syllogism enters; a syllogism missing from a model's prediction file is a refusal, not a skipped row
- **Unit:** one (model, rule, syllogism) combination; the kept number is the mean improvement over all 2,240

## Task (verbatim)

  ```text
  Evaluate the predictions made by various syllogistic reasoning models and NVC (No Valid Conclusion) rules against the MFA (most frequent answer) benchmark. The program should output a CSV file named accuracies.csv saved to pred_results/, detailing each model's predictions, the true answers, and the improvements achieved by the NVC rules.

  Output format: `pred_results/accuracies.csv`, a CSV file with the columns model, nvc, task, prediction, plain_prediction, truth, improvement, hit_model, hit_nvc, in this order, and one row per model, rule and syllogism (7 models x 5 rules x 64 syllogisms = 2240 rows, in any order). `model` is the model's name (its prediction file's name without `.csv`); `nvc` is the rule's output name; `task` is the syllogism in CCOBRA's encoding (for example AA1); `plain_prediction` holds the model's predicted responses and `prediction` the predicted responses after applying the rule, each in CCOBRA's response encoding, joined by `;` in the order of the model's prediction file (`NVC` for no valid conclusion); `truth` is the MFA response; `hit_model` and `hit_nvc` are the scores of the original and of the rule-applied prediction; `improvement` is hit_nvc minus hit_model.

  Compute the MFA benchmark, model and rule scores, and improvements yourself from Ragni2016.csv, the supplied model prediction files, and the rule implementations. Do not use accuracies_data_for_plot.csv or ind_data_for_plot.csv as sources of result values or to choose, tune, or validate your computation.

  Evaluate all seven supplied models (Atmosphere, Conversion, MMT, Matching, PHM, PSYCOP, VerbalModels) with each of these five supplied rule implementations from benchmark/datasets/nvc/scripts/prediction_errors/rules/: partneg.PartNeg, emptystart.EmptyStart, figural.Figural, negativity.Negativity, and particularity.Particularity. Use their output names PartNeg, EmptyStart, FiguralRule, NegativityRule, and ParticularityRule, respectively. Include every model-rule combination.

  For each syllogism, score a non-empty prediction list containing n answers as 1/n if it contains the MFA answer, and as 0 otherwise. Apply this rule to both the original model prediction and the prediction after applying an NVC rule. Report improvement as the latter score minus the original model score.
  ```
